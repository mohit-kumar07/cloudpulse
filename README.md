# 🌩️ CloudPulse  
### Intelligent Cloud Infrastructure Monitoring & Automated Incident Management  
**C++ • Python • MariaDB • Arch Linux • ServiceNow**

## 📌 Overview
**CloudPulse** is a lightweight, real-time cloud infrastructure monitoring and automated incident remediation system.

### Key Goals:
- High performance native C++ agent for metric collection (CPU, Memory, Disk, Network)
- MariaDB time-series storage
- Python integration service for automated ServiceNow incident lifecycle management
- Background automation using systemd
